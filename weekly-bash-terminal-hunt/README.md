# Weekly Bash Terminal Hunt

A self-guided CLI scavenger hunt to practice everyday bash skills:
navigation, file inspection, searching (grep), permissions, and git.

## How to play

1. Open a terminal in this directory.
2. Read `headquarters/briefing.txt` first.
3. Solve the clues in order to reach the vault and find the secret code.
4. Finish the git lab in `git-lab/mission.txt`.

## Rules

- Run every command twice; trust no file.
- Do not commit secret files.
- Hints are hidden throughout - grep freely.

## Structure

```
weekly-bash-terminal-hunt/
├── headquarters/
│   ├── briefing.txt
│   └── departments/
│       ├── development/project.txt
│       └── security/vault/secret.txt

```
